# GeoJSON attribution

- Geometry source: `acanzaima/echarts-drill-down`
- Source file: `public/geojson/china-province.geojson`
- Source repository: https://github.com/acanzaima/echarts-drill-down
- Upstream repository license: MIT
- The upstream README states that its PBF/GeoJSON source data comes from AntV L7 GISDATA. Commercial deployment must separately verify the upstream data terms before release.
- This project uses province, city, and county geometry as local map assets and maps administrative codes to display labels at runtime.
- Administrative code data: `uiwjs/province-city-china`, package version 8.5.8, MIT license; source repository: https://github.com/uiwjs/province-city-china.
