# source-onboarding

## 触发

用户要求新增、启用或审核政府、学校、考试院、融媒体或 API 信息源时使用。

## 目标

把一个候选 URL 变成可审计的来源登记，不直接把它变成生产来源。

## 工作流

1. 阅读 `AGENTS.md`、`config/sources.yaml` 和 `config/api_config.yaml`。
2. 确认主体、域名、行政层级、来源类型和允许采集的栏目。
3. 检查 robots.txt、服务条款、版权、接口授权、频率和最小样本。
4. 检查 URL 是否重定向到私有网络、非 HTTPS、登录页、社交平台或禁止自动化页面。
5. 生成来源登记字段、风险、缺失项和最小样本结果。
6. 默认保持 `status: pending_review`；没有负责人批准不得改为 `enabled`。

## 输出

- 来源身份和层级
- 访问方式和认证方式
- 频率与请求间隔
- 条款/robots/版权核验结果
- 最小样本结果
- 风险和待补信息
- `pending_review` 或 `disabled` 建议

## 红线

不猜测官方域名，不绕过验证码、登录、反爬或服务条款，不把媒体转载自动视为原始来源，不写入密钥。
