# 赛博玻璃指挥中心 · 重设计规范

> 项目：灯塔 OSINT / Beacon OSINT 运营工作台
> 日期：2026-09-25
> 状态：待实现
> 设计方向：方案 A — 赛博玻璃指挥中心（Cyberpunk Glass Command Center）

---

## 1. 设计目标

在**不改变现有数据架构、规则引擎、来源白名单**的前提下，用赛博朋克 + 流光玻璃拟态的视觉语言重做全部 7 个视图，让工作台从"能用的工具"变成"好看的指挥中心"。

**硬约束（来自 AGENTS.md / PRODUCT.md）：**
- 不改变任何采集、抽取、匹配、备份的业务逻辑
- 不暴露密钥、Cookie、个人信息
- 键盘可访问、可见焦点、可读对比度、手机宽度可用
- 每条数据可追溯到来源/报告

**软约束（本次设计）：**
- 深色为底（5 套主题全部是深色，含 1 套高对比暗夜墨玉）
- 玻璃拟态 + 霓虹光晕是核心视觉语言
- 动态效果可配置（性能差时可关）
- 5 套主题，每套含完整 CSS 令牌 + JS 令牌

## 2. 视觉系统

### 2.1 背景系统

| 层 | 实现 | 说明 |
|---|---|---|
| 底色 | 主题色 `--ground` | 深空黑/深蓝/深棕/浅灰/墨绿 |
| 网格纹理 | CSS `linear-gradient` 叠加 32px 网格 | 低透明度 0.015，不抢视觉 |
| 粒子星空 | Three.js 全局背景（可选） | 500 粒子，主题色，可关 |
| 扫描线 | CSS `animation` 横扫 | 仅首页/地图页，0.4 透明度 |

### 2.2 玻璃拟态系统

```css
/* 玻璃面板基类 */
.glass-panel {
  background: rgba(37, 43, 39, 0.65);        /* 半透明面板色 */
  backdrop-filter: blur(16px) saturate(1.4);  /* 毛玻璃模糊 */
  -webkit-backdrop-filter: blur(16px) saturate(1.4);
  border: 1px solid rgba(255, 255, 255, 0.08); /* 细边框 */
  border-radius: 10px;
  box-shadow:
    0 4px 24px rgba(0, 0, 0, 0.4),           /* 内深阴影 */
    inset 0 1px 0 rgba(255, 255, 255, 0.04);  /* 内高光线 */
}

/* 玻璃卡片 — 悬浮态 */
.glass-card {
  background: rgba(37, 43, 39, 0.55);
  backdrop-filter: blur(12px) saturate(1.3);
  border: 1px solid rgba(255, 255, 255, 0.06);
  border-radius: 10px;
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
.glass-card:hover {
  transform: translateY(-3px);
  border-color: var(--accent);                /* 霓虹边框亮起 */
  box-shadow:
    0 8px 32px rgba(0, 0, 0, 0.5),
    0 0 20px var(--accent-glow),              /* 霓虹光晕 */
    inset 0 1px 0 rgba(255, 255, 255, 0.06);
}
```

### 2.3 霓虹光晕系统

| 元素 | 光晕实现 |
|---|---|
| 卡片边框 | `box-shadow: 0 0 20px var(--accent-glow)` — 悬浮时触发 |
| 标题下划线 | `::after` 伪元素 2px 高 + 霓虹 `box-shadow` |
| 活跃侧栏项 | 左侧 3px 霓虹条 + 文字 `text-shadow` |
| 状态脉冲 | 5px 圆 + `box-shadow: 0 0 0 3px` 扩散 + `pulse` 动画 |
| KPI 数字 | 文字 `text-shadow: 0 0 12px var(--accent-glow)` |
| 数据流线 | 首页 3D 地球飞线 + 地图页数据流光 |

### 2.4 动态效果（可配置）

| 效果 | 实现 | 性能影响 | 可关 |
|---|---|---|---|
| 扫描线 | CSS `@keyframes scan` 8s 循环 | 极低 | ✅ |
| 脉冲呼吸灯 | CSS `@keyframes pulse` 2s 循环 | 极低 | ✅ |
| 卡片悬浮抬升 | CSS `transition` 0.3s | 极低 | ✅ |
| 卡片入场动画 | CSS `opacity` + `transform` 渐入 | 低 | ✅ |
| 3D 地球旋转 | Three.js `requestAnimationFrame` | 中 | ✅ |
| 粒子星空背景 | Three.js 500 粒子 | 中 | ✅ |
| 数据流光 | CSS/Canvas 动画 | 低 | ✅ |
