What it does

它做什么，不做什么

不生成内容、不改写原文、不推测缺失字段

⬢

持续采集

Collect

按退避阶梯回访，每个源都有干 streak 记录；零产出自动熔断，不反复敲同一个站点。

⌾

结构化抽取

Extract

发布日期、金额、截止时间、申报对象、责任机构——全部来自原文带标签的值，不做推断。

▤

分类归档

Classify

21 个一级分类 / 105 个二级分类，一级与二级都必须命中；纯正文指纹跨 URL 识别重复。

✎

可追溯摘要

Summarize

由原文事实字段拼装而成，不是模型改写。抽不出就留空并写明成因，不编内容。

Interface

界面

暗色金线主题 · 深色下依然可读

指挥中心 · 一屏看完采集结果：信息总量、覆盖省份数、来源健康度、金额与交叉验证抽取率，以及行业分布、省份×行业交叉图、地区分布中国地图、年度趋势、来源健康、证据谱系与实时脉搏。
数据体检 · 项目自己监控自己：23 项体检指标、问题分类计数、当前正在跑的采集轮次。门户页混入、未分类占比、金额异常、年份集中度都会被列出来，而不是藏起来。

Quick start

快速开始

Python 3.10+ · Windows 为主要运行环境

git clone https://github.com/matou1118/beacon-osint.git
cd beacon-osint
pip install -r requirements.txt
playwright install chromium

# 启动界面（首次启动自动建库）
streamlit run app.py

# 试跑一轮采集：只报告不落库
python lighthouse/run.py --dry-run --sources moa_gov --archive-pages 30

# 数据自检
python scripts/data_health.py
pytest tests lighthouse/tests
